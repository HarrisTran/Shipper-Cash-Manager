# Shipper Cash Manager (SCM)

Ứng dụng Flutter giúp quản lý luồng tiền, giao dịch và trạng thái công việc của shipper theo thời gian thực.

## Tính năng chính
- Quản lý giao dịch và trạng thái thanh toán của shipper.
- Thống kê tiến độ công việc (đang chờ/đã hoàn thành).
- Giao diện trực quan, tối ưu hóa (Material 3, Clean Architecture).

## Cài đặt & Chạy
```bash
flutter pub get
flutter run
```
